# 1) Caja / Dispensar (`/sales/new`)

### Estructura general

* **AppLayout**

  * **TopBar**
  * **SideNav**
  * **PageHeader** (“Caja” + fecha/hora opcional)

### Componentes de la página

**A. CustomerSelect**

* Input tipo buscador con dropdown
* Estado: vacío / seleccionado
* Acciones:

  * **+ NewCustomerButton** (abre modal)
  * **ClearCustomerButton**

**B. TicketItemsList**
Contenedor de líneas del ticket.

* **TicketItemRow** (repetible)

  * **ProductSearchSelect**

    * búsqueda + dropdown
    * muestra stock actual en la opción (pequeño)
  * **StockBadge**

    * “Stock: 275g” (y color si bajo)
  * **GramsInput**

    * stepper o input numérico
    * validación inline (rojo si > stock o <=0)
  * **LineSubtotal**

    * “€XX.XX” automático
  * **RemoveLineButton** (icono X)

* **AddItemButton**

  * “+ Añadir producto”
  * (alternativa: siempre hay una fila vacía al final)

**C. TicketSummaryCard**
Bloque fijo (derecha o abajo en móvil)

* **TotalAmountDisplay** (muy grande)
* **CashGivenInput** (“Entrega €”)
* **ChangeDisplay**

  * verde si >=0
  * rojo si falta
* **ConfirmSaleButton**

  * deshabilitado si:

    * no hay cliente
    * no hay items
    * grams inválidos
    * cashGiven < total
* **ResetTicketButton** (opcional, “Vaciar”)

**D. Feedback / estados**

* **InlineValidationMessage** (por línea o general)
* **Toast / Snackbar**

  * “Venta registrada”
* **SuccessOverlay** (opcional)

  * resumen + botones: “Nueva venta”, “Ver cliente”

**E. Modal: NewCustomerModal**

* **ModalShell**
* **CustomerFormMini** (nombre + notas)
* **PrimaryButton** “Crear”
* **SecondaryButton** “Cancelar”

# 5) Crear producto (`/products/new`)

### Componentes

* **PageHeader** (“Nuevo producto”)
* **ProductForm**

  * **TextInput** Nombre (required)
  * **CategorySelect** (required)
  * **PricePerGramInput** (required > 0)
  * **Textarea** Descripción (optional)
  * **InitialStockInput** (required >= 0)
* **FormActions**

  * **PrimaryButton** “Crear”
  * **SecondaryButton** “Cancelar”
* **FormFieldError** (por campo)
* **Toast** éxito/error

# Componentes transversales (globales)

Estos se usan en varias páginas:

* **AppLayout / SideNav / TopBar**
* **PageHeader**
* **PrimaryButton / SecondaryButton / IconButton**
* **ModalShell**
* **DataTable** (tabla genérica)
* **FormField** (label + input + error)
* **Toast/Snackbar**
* **ConfirmDialog** (si alguna vez pides confirmación)
* **LoadingSkeleton / Spinner**
* **EmptyState / ErrorState**

---

Si quieres, el siguiente paso UX puro sería:

* definir **jerarquía visual exacta** de Caja (qué va grande, qué va pequeño),
* y luego hacer **wireframe textual** página por página (con disposición desktop + mobile).
