Perfecto, voy **a saco y sin humo**.

# 🧩 EPIC 1 — Gestión de productos (mercancía)

### US-1.1 Crear producto

> Como **operador**, quiero **crear un nuevo producto** indicando nombre, categoría, €/gr, descripción y stock inicial,
> para **tenerlo disponible para dispensar**.

**Criterios básicos**

* El stock inicial se registra como movimiento
* El producto queda activo

---

### US-1.2 Editar producto

> Como **operador**, quiero **editar los datos de un producto existente**,
> para **mantener la información actualizada**.

---

### US-1.3 Ver listado de productos

> Como **operador**, quiero **ver todos los productos con su stock actual**,
> para **saber qué hay disponible**.

---

### US-1.4 Ver detalle de producto

> Como **operador**, quiero **ver la ficha de un producto**,
> para **consultar su información completa**.

---

### US-1.5 Ver historial de recargas y movimientos

> Como **operador**, quiero **ver el historial de recargas de un producto**,
> para **saber cuándo y cuánto stock se ha incorporado**.

---

# 🧩 EPIC 2 — Gestión de stock

### US-2.1 Añadir stock a producto existente

> Como **operador**, quiero **añadir cantidad a un producto existente**,
> para **reponer stock**.

**Criterios**

* Se registra como recarga
* Aumenta el stock disponible

---

### US-2.2 Consultar stock actual

> Como **operador**, quiero **ver el stock actual de cada producto**,
> para **saber cuánto queda disponible**.

---

# 🧩 EPIC 3 — Dispensación / ventas

### US-3.1 Dispensar producto a un usuario

> Como **operador**, quiero **dispensar X gramos de un producto a un usuario**,
> para **realizar una venta**.

**Criterios**

* Se introduce cantidad en gramos
* Se descuenta stock

---

### US-3.2 Cálculo automático del precio

> Como **operador**, quiero que **la app calcule automáticamente el importe**,
> para **evitar errores de cálculo**.

---

### US-3.3 Cálculo del cambio

> Como **operador**, quiero **introducir el dinero entregado y ver el cambio**,
> para **cerrar la venta correctamente**.

---

### US-3.4 Venta con varios productos

> Como **operador**, quiero **dispensar varios productos en una misma operación**,
> para **registrar una venta completa**.

---
